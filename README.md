# MNIST-Digit-Classification
#Project Overview

This project was completed as part of the AI Internship at Naviotech Solution Pvt. Ltd.

The objective of this project is to classify handwritten digits (0–9) using a Convolutional Neural Network (CNN) trained on the MNIST dataset.

#Technologies Used

Python, 
Google Colab, 
TensorFlow, 
Keras, 
NumPy, 
Matplotlib, 
Scikit-learn.

#Dataset

The project uses the MNIST dataset, which contains:

60,000 training images,
10,000 testing images,
28 × 28 grayscale images,
10 classes (digits 0–9).

#Project Workflow

1.Load the MNIST dataset

2.Preprocess and normalize the images

3.Build the CNN model

4.Train the model

5.Evaluate the model

6.Predict handwritten digits

#Project Files

mnist_digit_classification.ipynb – Source code

Project_Report.pdf – Project report

Presentation.pptx – Project presentation

#Results

The CNN model successfully classifies handwritten digits with high accuracy on the MNIST test dataset.
